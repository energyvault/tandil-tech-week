# Tandil Tech Week 2026

Sitio web de Tandil Tech Week, dedicado a la tecnología, la programación, la innovación y la comunidad tecnológica.

## Funcionalidades

- **Inicio:** presentación del evento, navegación y redes sociales oficiales.
- **Agenda:** consulta de actividades, horarios, fechas y ubicaciones.
- **Detalle de eventos:** descripción, duración, público destinatario y cronograma.
- **Google Maps:** acceso a la ubicación de cada evento.
- **Google Calendar:** opción para agregar eventos al calendario.
- **Transmisiones en vivo:** acceso a Twitch cuando el evento se transmite.
- **Sponsors:** información, logotipos y enlaces a organizaciones patrocinadoras.
- **Solicitud de eventos:** formulario para proponer y organizar nuevas actividades.
- **Solicitud de patrocinio:** formulario para presentar propuestas de colaboración.
- **Galería:** espacio destinado a imágenes de eventos anteriores.

## Diseño

Interfaz moderna y adaptable, con estética tecnológica, fondos oscuros y detalles verde neón.

## Estado actual

Proyecto de demostración desarrollado con Flutter y Dart. Los eventos y sponsors utilizan datos de ejemplo. Las solicitudes preparan correos electrónicos y no se almacenan en una base de datos.
